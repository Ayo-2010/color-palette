# Palette Studio

Generates and saves colour palettes.

## Features

- Five-colour palettes built from HSL
- Lock individual colours while regenerating
- Switch between HEX and RGB
- Save palettes to your browser

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
